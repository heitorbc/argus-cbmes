## Achados

- **Inline expand é UX melhor que modal pra Trocas** — mantém a linha
  visível no contexto, sem perder posição na tabela. Framer Motion
  `height: auto` anima suavemente.
- **Drop-zone proeminente no top do form** transforma uma feature
  "escondida" do mobile (botão pequeno) em destaque visual. Adoção
  esperada: +50% pelo sargenteante.
- **MilitarSelect com `onChange(nf)` direto** funciona como
  "adicionar militar" sem precisar de UI extra (caller clear depois).
- **Trocas é read-only** — planilha externa é a fonte; admin pode
  sincronizar para puxar mudanças.
