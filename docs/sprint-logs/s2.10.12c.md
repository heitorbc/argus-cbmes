## Por que mudar

A página mobile de escalas (`pages/escalas.tsx`, 1021 linhas) coloca
calendário + composição empilhados verticalmente — em desktop, ~75% da
tela fica vazia. O sargenteante consulta múltiplos meses por dia e
benefica de:

- Lista de meses sempre visível (não precisa voltar)
- Calendário do mês inteiro num só viewport
- Composição q1 e q2 lado-a-lado (comparação visual rápida)
- Navegação por teclado ←/→

Esta sub-sprint entrega só a **visualização/exploração**. Upload XLSX +
import com diff permanecem no mobile por ora — serão integrados em
sprint futura se o sargenteante usar o WEB para essa task.

## Achados

- **Cache 5min é generoso** para escalas (mudam só quando há novo upload).
  Combina bem com `staleTime` + React Query persist do S2.10.9c — segunda visita à página é instantânea.
- **Grid 7-cols + 35 células** cobre 6 semanas (alguns meses precisam).
  Padding inicial calculado a partir do `Date(ano, mes-1, 1).getDay()`.
- **Marcador ⚠ por NF não-resolvida** é UX direta — sargenteante vê
  imediatamente onde tem problema sem precisar abrir Mapa Força.
