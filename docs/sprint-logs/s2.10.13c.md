# Sprint S2.10.13c — Agenda filters revistos (default 4 fontes + ChOp condicional)

**Data:** 2026-05-28
**Foco:** Terceira sub-sprint do roadmap S2.10.13. Reduz saturação visual
da página `/agenda` ativando por default apenas 4 fontes core (Escala
Mensal, Especial, ISEO, Trocas) e tornando ChOp visível apenas para
militares habilitados na planilha externa.
**Tech Lead:** 2º SGT Heitor Barcellos Coelho
**Base:** S2.10.13b (Efetivo multi-unidade)

## Critérios de Pronto (DoD)

- [x] `fontesAtivas` default mudou de **todas as 9** para **4 core**: `escala_mensal`, `escala_especial`, `iseo_hospitais`, `troca_autorizada`
- [x] Persistência em `localStorage.argus.agenda.fontesAtivas` (recupera próxima sessão)
- [x] Loader robusto: ignora valores inválidos no localStorage
- [x] `chefe_operacoes` aparece como toggle **apenas** se o NF do user logado está em `chefesOperacoesHabilitados()`
- [x] Entries de ChOp são também filtradas client-side mesmo se o backend devolveu (defesa)
- [x] React Query: `staleTime` 24h para `chop-habilitados-me` (lista muda raramente; cache largo)
- [x] Ordem das fontes na UI prioriza as 4 core; ChOp por último
- [x] Pipeline verde: typecheck + lint + format + test
- [x] **657 testes api + 30 web = 687 passing** (sem novos tests — mudanças estruturais; smoke coberto por testes existentes)

## Por que mudar

A Agenda atual mostrava todas as 9 fontes ativas por default, causando
saturação visual (9 chips coloridos no topo + lista densa). Tech Lead
quer:

1. **Default minimalista** (4 fontes core) — o militar marca o que mais
   quer ver se precisar
2. **ChOp condicional** — visível só para os ~15 militares habilitados na
   planilha externa de Chefes de Operações; demais não veem a opção (ela
   nunca devolveria nada útil para eles).

## Entregas

### Frontend

**[apps/web/src/pages/agenda.tsx](apps/web/src/pages/agenda.tsx)** (MODIFIED)

- Novo constante `FONTES_DEFAULT: AgendaFonte[]` = 4 core fontes
- `loadFontesFromStorage()` helper: lê + valida JSON, filtra fontes inválidas
- `useEffect` persiste `fontesAtivas` em localStorage a cada mudança
- Novo `useQuery(['chop-habilitados-me', user.nf])`: lista habilitados, cache 24h
- `isChopHabilitado` = NF do user está na lista
- `fontesVisiveis` filtra ChOp para fora se não habilitado (omite o toggle)
- `itensFiltrados` aplica dupla defesa: fonte ativa + (ChOp → user habilitado)
- Ordem das fontes em `TODAS_FONTES` reorganizada (core no topo)

### Backend

**Sem mudanças.** O backend já retorna a Agenda completa; o filtro/ocultação
é client-side.

   Mensal, Especial, ISEO, Trocas
2. **User não-ChOp**: toggle "Chefe de Operações" **não aparece**

4. **Marcar/desmarcar fontes**: persistência funciona — recarregar página

5. **Marcar Dispensa**: items de dispensa aparecem na lista
6. **Cache 24h** do habilitados-me: trocar conta/login não revalida
   imediatamente (mas próxima refetch confirma corretamente o status)

## Achados

- **Cache 24h é generoso** para ChOp habilitado, mas correto: a lista
  muda no máximo 1×/ano na planilha externa.
- **Dupla defesa para ChOp** (filtra no toggle + no `itensFiltrados`)
  protege contra casos onde o user revogou ChOp recentemente mas o cache
  ainda não invalidou.
- **`AgendaFonte` é um union type** — usei guard com `TODAS_FONTES.includes`
  para validar valores do localStorage (evita injetar fontes inválidas).
