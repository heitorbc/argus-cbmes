## Verificação end-to-end

```bash
# 1. Mapa Força acessível
curl -sL "https://docs.google.com/spreadsheets/d/$GOOGLE_SHEET_ID_MAPA_FORCA/export?format=csv&gid=$GOOGLE_SHEET_GID_MAPA_FORCA" | head -10

# 2. Login Admin
curl -X POST http://localhost:3000/auth/login -H "Content-Type: application/json" \
  -d '{"nf":"3037509","senha":"<sua-senha>"}' -c /tmp/c.txt

# 3. Recursos do MF (deve incluir MERGULHO 01/02)
curl http://localhost:3000/mapa-forca/recursos -b /tmp/c.txt | jq '.[] | select(.recurso | startswith("MERGULHO"))'

# 4. Sentinelas: importar 05 MAIO 2026 e verificar GUARDA
curl "http://localhost:3000/escalas?ano=2026&mes=5" -b /tmp/c.txt | jq '.escala.composicao | map(select(.equipe=="C" and .viatura=="GUARDA"))'
# Esperado: 3 entries (Sent. 1, Sent. 2, Sent. 3)

# 5. Status viatura
curl http://localhost:3000/viaturas -b /tmp/c.txt | jq '.[] | {prefixo, status, funcaoOperacional}'
# Esperado: TE_110 com status='baixada'

# 6. Editar equipe de um dia
curl -X PUT "http://localhost:3000/escalas/2026/5/dia-equipe" -b /tmp/c.txt \
  -H 'Content-Type: application/json' -d '{"data":"2026-05-23","equipe":"D"}'

# 7. Salvar ajustes pré-turno
curl -X PUT http://localhost:3000/previa/2026-05-23/ajustes -b /tmp/c.txt \
  -H 'Content-Type: application/json' \
  -d '{"trocas":[],"escalaEspecial":{"matutina":{"militarRaw":"SGT BRUNO MELO"}},"notasServico":[{"codigo":"NS072"}],"dispensas":[]}'

# 8. Prévia com ajustes + mergulho + status correto
curl "http://localhost:3000/previa?data=2026-05-23" -b /tmp/c.txt | jq '{
  equipe,
  tripulacao_aquaticas: (.tripulacao | map(select(.equipe=="AQUATICAS"))),
  vtr_baixadas: (.viaturasOperacionais | map(select(.vtrStatus!="operacional"))),
  trocas, notasServico
}'

# 9. IDEO: 62 entries
curl http://localhost:3000/ideo -b /tmp/c.txt | jq '.entries | length'
# Esperado: 62
```

Frontend: http://localhost:5173 →

- `/cadastros/escalas`: importa XLSX → calendário aparece com 3 sentinelas distintas + modo "Editar escala" funcional
- `/previa?data=2026-04-23`: equipe CHARLIE, tripulação inclui mergulho (AQUATICAS), card de viatura com status colorido, seção "Ajustes pré-turno" expansível, botão "📋 WhatsApp" copia texto formatado para clipboard.

## Achados durante a implementação

- **Política pnpm 11 sobre build scripts**: `puppeteer` requer aprovação explícita
  para baixar Chromium (~200MB). Workspace.yaml deliberadamente não aprova; usamos
  `node node_modules/puppeteer/install.mjs` manualmente, rodamos o scrape, e
  removemos a dep. JSON congelado vai pro repo.
- **Mapa Força tem `SOMA DE RECURSO` no MEIO do bloco** da 1ª Cia (entre REPDEC 02
  e DRO/TELEFONISTA), não no fim. Parser pula essa linha e continua até `EQUIPAMENTOS`.
- **`LETRA_EQUIPE` ganhou AQUATICAS/STAFF**, mas `diaEquipe` continua restrito a
  A/B/C/D via novo type `LetraEquipeRotativa`. Compatibilidade preservada.
- **IDEO scraping**: o conteúdo do Google Sites é JS-renderizado em iframes que
  aparecem após `networkidle2`. Heurística do scraper espera 4s + procura
  parágrafos no padrão `^N) NOME` para extrair só os nomes (descarta as
  instruções de inspeção, que são os parágrafos seguintes).
- **Site IDEO tem typos** que vieram pro JSON (ex.: "Blocante (rescucender)" em
  vez de "descender"). Aceitar e deixar correção via tela `/cadastros/ideo`
  do Admin (que sobrescreve o seed).
- **Status `vtrStatus` no `viaturasOperacionais`**: agora retornamos TODAS as
  viaturas com status, não só operacionais. O WhatsApp inline `***#BAIXADA#***`
  precisa saber quais estão baixadas/emprestadas para mostrar.
