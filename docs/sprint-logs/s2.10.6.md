## Motivação

Reorganização das Conferências do serviço conforme planejamento S2.10.4+:

1. **Renomes** alinham com nomenclatura institucional
2. **Materiais sai da Conferência da Viatura** — vira módulo separado, podendo ser feita por qualquer militar escalado, em momento desacoplado do MF CIODES
3. **Termo de Responsabilidade do COV/Motorista** com auto-fill EFETIVO + Viatura
4. **Checklist de 25 itens** (Inspeção externa, Motor, Cabine, Equipamentos de emergência)
5. **Conferência de Materiais nova** com cadastro admin de compartimentos por viatura ou local
6. **Contador regressivo até 8h** sinaliza prazo institucional do 1º preenchimento do MF CIODES

## Schema novo (migration `20260518000000_s2_10_6_conferencias_cov_materiais`)

```prisma
model ConferenciaCov {
  id            String   @id @default(cuid())
  data          String
  vtrPrefixo    String
  motoristaNf   String
  termoAceitoEm DateTime
  checklist     Json     // ChecklistCovItem[]
  observacao    String?
  @@unique([data, vtrPrefixo, motoristaNf])
}

model CompartimentoMaterial {
  id            String   @id @default(cuid())
  contexto      String   // 'viatura:ABTS_011' | 'local:SALA_FISCAL'
  contextoLabel String
  compartimento String
  materiais     Json     // string[]
  ordem         Int
  ativo         Boolean
}

model ConferenciaMaterial {
  id             String   @id @default(cuid())
  data           String
  contexto       String
  realizadoPorNf String
  realizadoEm    DateTime
  itens          Json     // ItemConferenciaMaterialV2[]
  observacao     String?
  @@unique([data, contexto])
}
```

Aplicada via `prisma migrate diff` + `migrate deploy` (mesmo padrão de S2.10.4).

## Decisões implementadas

| #                                  | Decisão                                                                                                                                                                       | Onde                         |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| Termo COV = só timestamp + NF (D4) | `ConferenciaCovService.registrar` salva `termoAceitoEm: new Date(input.termoAceitoEm)` e `motoristaNf: user.nf`                                                               | conferencia-cov.service.ts   |
| Materiais desacoplada do MF        | Página `/conferencia-materiais` pública para militar escalado (sem gating de estado de serviço)                                                                               | conferencia-materiais.tsx    |
| Cadastro admin de compartimentos   | `viatura:<prefixo>` ou `local:<slug>` como `contexto`; admin CRUD livre                                                                                                       | compartimentos-materiais.tsx |
| Seed dev de 8 defaults             | `onModuleInit` em `CompartimentosMateriaisService` cria 5 viaturas + 3 locais (AU 154, ABTS 011, AR 044, ATB 001, TE 110, SALA_FISCAL, ALMOXARIFADO_OPERACIONAL, GUARITA_QCG) | service.ts                   |
| Contador 8h                        | Componente puro client-side, atualiza a cada minuto. Cor segue threshold de minutos restantes                                                                                 | CountdownAteOito.tsx         |
